# CISA

Neutrales Anmeldeportal: https://cisa-anmeldeportal.pages.dev

CISA befindet sich im privaten Test. Software-Downloads und automatische Update-Releases sind noch nicht öffentlich freigegeben. Dieses Repository enthält ausschließlich die öffentliche Portalseite und keine Installer, Unternehmensdaten oder Zugangsdaten.

Der gemeinsame Einstieg führt zum geschützten Portal des ausgewählten Unternehmens. Unternehmensdaten und Berechtigungen werden dort verwaltet.

Die Entwicklungsdateien werden in einem getrennten privaten Repository gepflegt.
